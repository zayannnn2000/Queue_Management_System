# queue-app

The Next.js app for the token-based clinic queue. See the [repository README](../README.md) for how to run it,
the ordering rule, the wait-time formula, assumptions and trade-offs, and [`../CLAUDE.md`](../CLAUDE.md) for the
full queue rules.

```bash
npm install
npm run dev        # http://localhost:3000
npm test           # Vitest
npm run test:e2e   # Playwright
```
